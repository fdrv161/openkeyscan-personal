# OpenKeyScan для REAPER

Определяет тональность (обычное название, Camelot и Open Key) и темп (BPM) выбранных элементов прямо в REAPER. Своего окна у скриптов нет: выделили элемент, нажали горячую клавишу, получили ответ.

Аудиофайлы только читаются, в них ничего не записывается.

Названия действий и сообщения скриптов на английском, как и сам REAPER.

## Требования

- Windows 10 или 11, 64 бита.
- REAPER 6 или новее.
- Около 200 МБ свободного места.

## Установка

1. В REAPER откройте Options, затем Show REAPER resource path in explorer/finder, и зайдите в папку Scripts.
2. Распакуйте туда папку OpenKeyScan из архива целиком. Внутри должны лежать файлы .lua, справка и папка engine.
3. Откройте Actions, затем Show action list, нажмите New action, затем Load ReaScript и выберите файл «OpenKeyScan - Install actions.lua».
4. Один раз запустите действие «OpenKeyScan - Install actions». Оно добавит в список остальные три действия. Файл OpenKeyScan_core.lua загружать не нужно, это общий код.
5. По желанию назначьте действиям горячие клавиши.

Обновление с версии 2.0.0: имена файлов действий изменились. Удалите старую папку OpenKeyScan, уберите старые действия из списка, установите всё заново по шагам выше и снова назначьте горячие клавиши.

## Действия

- «OpenKeyScan - Key and BPM of selected items» сообщает результат для каждого выбранного элемента, например «beat: 88 BPM, 7A, D minor».
- «OpenKeyScan - Key and BPM, set project tempo» делает то же и ещё:
  - выставляет темп проекта по первому выбранному элементу (если в проекте нет маркеров темпа);
  - дописывает тональность в имя дорожки: «instr» становится «instr [D minor, 7A]»;
  - сдвигает все элементы проекта так, чтобы первая сильная доля бита легла на линию такта.

  Всё это отменяется одним Ctrl+Z.
- «OpenKeyScan - Cycle BPM range» по кругу меняет диапазон, к которому приводится темп: 50–100, 70–140 или без приведения. Выбор запоминается.

Анализируется исходный файл элемента целиком. MIDI и пустые элементы пропускаются.

## Что нужно знать

- По умолчанию темп приводится к диапазону 50–100 BPM: 133 BPM будет показан как 66,5. Так удобнее для хип-хопа и трэпа. Полный темп включается действием «Cycle BPM range».
- Если сеть не уверена в темпе, к ответу добавляется «tempo uncertain, check by ear» (темп неуверенный, проверьте на слух).
- Если в тегах файла уже записаны и BPM, и тональность, первое действие отвечает по тегам, без анализа, и говорит «From file tags». Теги бывают неточными: чтобы проверить анализом, используйте второе действие, оно теги не читает.
- Анализ трека длиной 3 минуты занимает пару секунд. Самый первый запуск после распаковки бывает дольше: Windows проверяет новые файлы.
- Результаты запоминаются в папке engine\cache. Повторный анализ того же файла занимает доли секунды. Если файл перезаписали, он анализируется заново.
- Без OSARA итог показывается окном.

## Работа со скринридером

Если в REAPER установлена OSARA, все сообщения (начало анализа, итог, ошибки) произносятся скринридером: NVDA, JAWS или Экранным диктором. Окна при этом не появляются, а фокус остаётся там, где был.

## Удаление

Удалите папку OpenKeyScan из Scripts и уберите действия из списка действий. Временные файлы анализа лежат в папке %TEMP%\OpenKeyScan-REAPER и удаляются сами.
